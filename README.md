# Experiment 2 – Data Handling with Python

This repository contains the files for **Experiment 2: Understanding Data with Programming**.

## Files

- `EXP2_Data_Handling.ipynb` – simple Jupyter Notebook with the experiment activities, outputs to generate, inferences, post-lab answers and conclusion.
- `exp2_data_handling.py` – Python script version of the notebook code.
- `urban_climate.csv` – dataset used in the experiment.
- `Experiment_2_Instructions.pdf` – original experiment instructions supplied for this practical.
- `EXP2_notebook.pdf` – printable notebook/report version (if included).

## Requirements

- Python 3
- Jupyter Notebook or JupyterLab
- pandas
- numpy
- matplotlib

Install the libraries:

```bash
pip install pandas numpy matplotlib jupyter
```

## How to run

1. Download or clone this repository.
2. Open the project folder in Jupyter Notebook or JupyterLab.
3. Open `EXP2_Data_Handling.ipynb`.
4. Make sure `urban_climate.csv` is in the same folder.
5. Run the notebook cells from top to bottom.

To run the Python script instead:

```bash
python exp2_data_handling.py
```

## Notes

- The notebook uses the provided urban climate CSV dataset.
- The notebook includes simple code and short inferences written in a student-friendly style.
- Some cells create tables or plots; run the cells to see their outputs.
